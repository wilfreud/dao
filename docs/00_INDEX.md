# Documentation index

Read in this order when learning the project:

1. `01_PRODUCT_SCOPE.md` — what V0 is and is not.
2. `02_ARCHITECTURE.md` — module boundaries and repository shape.
3. `03_STACK_AND_DEPENDENCIES.md` — packages/crates and install policy.
4. `04_CONTRACTS.md` — stable TypeScript ↔ Rust contracts.
5. `05_APP_SHELL_AND_SEARCH.md` — launcher, registry, navigation, intent search.
6. `06_DROP_SERVER_SPEC.md` — full LAN drop-server behavior.
7. `07_ENV_SCRUBBER_SPEC.md` — format-preserving dotenv redaction.
8. `08_SECURITY.md` — capability and threat boundaries.
9. `09_TEST_STRATEGY.md` — test portfolio and acceptance checks.
10. `10_DESIGN_SYSTEM.md` — visual/interaction direction.
11. `11_ADDING_A_TOOL.md` — repeatable extension procedure.
12. `12_DECISIONS.md` — explicit architectural decisions and rejected complexity.
13. `13_RESEARCH_SOURCES.md` — research snapshot and upstream docs.

The `handoff/` files are implementation tasks, not reference documentation.
